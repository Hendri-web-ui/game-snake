# Snake Game

A simple browser-based Snake game built with HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a browser, or view the deployed GitHub Pages site.
2. Use the arrow keys or `WASD` to move the snake.
3. Eat the red food to grow and increase your score.
4. Avoid hitting the wall or your own body.
5. Press the space bar or the button to restart.

## GitHub Pages deployment

After pushing this repo, enable GitHub Pages in the repository settings:

- Go to `Settings` → `Pages`
- Set the source to `Deploy from a branch`
- Choose the `main` branch and `/ (root)` folder
- Save

Then GitHub will publish a live URL such as:

https://hendri-web-ui.github.io/game-snake/

## Local run

You can also run it locally with any static file server. For example:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000
